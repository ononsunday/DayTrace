# Windows 运行与验收

## 打开和退出

从源码运行前，按 README 安装依赖。运行包需要解压完整目录后打开 `DayTrace.exe`。关闭主窗口会隐藏到托盘；使用托盘“完全退出”停止统计。

同一数据目录只允许一个实例。升级前先退出旧实例，以免第二次启动只是唤起旧窗口。

## 人工检查

1. 用独立数据目录启动程序，确认六个页面能打开，浅色和深色主题可切换。
2. 分别切换前台模式、活跃模式，在两个应用间切换，检查保存后的时间轴。
3. 在活跃模式下等待超过空闲阈值，再恢复输入，检查空闲时间没有持续累计。
4. 关闭窗口，确认托盘仍在；从托盘打开窗口，再选择“完全退出”。
5. 填写日记并切换日期，重启后确认内容保留。检查导出、备份和恢复。
6. 按需要检查锁屏与解锁、休眠与唤醒、全屏游戏和受权限限制的进程。
7. 检查显示缩放为 100%、150% 和 200% 时的文字、按钮和窗口布局。

这些步骤是验收清单。是否已执行以及结果如何，以当前验证报告为准。

## 数据保护

测试时使用独立的 `DAYTRACE_DATA_DIR`，不要把正式日记和使用记录用于公开截图。程序运行时不要单独移动 SQLite 的 WAL/SHM 文件。

## 资源占用

不同系统、依赖版本、页面和数据规模会影响内存与 CPU。`scripts/measure_performance.py` 可在独立环境中测量；短时间测量不能证明长期运行表现。
